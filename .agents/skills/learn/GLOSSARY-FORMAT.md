# GLOSSARY.md format

The canonical language for this topic. Lessons, records, and references all use these terms. Building it is itself learning: compressing a concept into a tight definition is evidence the user understands it.

```md
# {Topic} glossary

**Progressive overload**:
Systematically increasing the demand on a muscle over time — via load, volume, or intensity.
_Avoid_: pushing harder, levelling up
```

Rules:

- **Add a term only when the user understands it** — the glossary records compressed knowledge; it isn't a dictionary to learn from.
- **Be opinionated.** Pick the best word for each concept; list the rest as aliases to avoid.
- **Tight definitions.** One or two sentences: what the term *is*, not how to do it.
- **Use glossary terms inside other definitions** — that's what makes later, complex terms cheap to define.
- **Revise as understanding deepens.** Update in place; no stale entries.
